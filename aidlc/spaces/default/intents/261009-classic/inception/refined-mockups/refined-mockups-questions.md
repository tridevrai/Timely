# Refined Mockups Questions

There are no rough mockups for this project (the plan skips Ideation), so the
screens are designed directly from the 32 approved stories and the
requirements. Already settled: a responsive web app for Mac and iPhone (NFR1),
WCAG 2.1 AA with full keyboard use and no color-only status (NFR6), and no
themes or appearance settings in version 1 (Q14). These questions set the
screen layout and the main interactions.

## Question 1: How should you move around the app on your phone?

A. A bottom tab bar with 4 tabs: Today, Capture, Sort, Lists (Delegated, Deferred, Archive, Summary inside Lists) (suggested)
B. One "Today" home screen, with capture and sort opened as sheets from buttons on it
C. A single scrolling page with everything stacked
X. Other (please specify)

[Answer]: X - Make it minimalist

## Question 2: How should sorting the unsorted items feel?

X. Other (please specify)
